# novo-html

新魔方 AI4S 风格的 16:9 单页 HTML 报告 / 幻灯片生成技能。

锁风格与配色，不锁版式——结构按内容长什么样来定。

## 安装

把本目录放进 DSH 的用户级技能根目录即可（保存即生效，无需重启）：

```sh
mkdir -p ~/.dsh/skills
cp -R novo-html ~/.dsh/skills/
```

也可以只对单个仓库生效，放到 `<项目根>/.dsh/skills/novo-html/`。

结构：

```
novo-html/
├── SKILL.md                     # 规范：配色、字号、版式选择、自查清单
└── templates/slide-16x9.html    # 参考样例，不是必填模子
```

## 用起来

对 agent 说：

> 用 novo-html 风格做一页，主题是……

或者：

> 按上次那个 HTML 风格，把这份材料排成一页

## 规范要点

**三条铁律**（与版式无关，永远适用）：

1. 一页只用三种色相：绿（结构与结论）、红（强调与编号）、中性灰
2. 深绿出现得少才有分量
3. 红色只做强调，整页面积控制在一成以内

**固定的识别特征**：1600×900 画布、页眉三件套（眉标 → 标题 → 副标题 + 绿线）、右上角 logo、点阵纹理。其余分栏数、面板数、要不要流程图、主图多大，全由内容决定。

**不做**：底部结论 banner（结论写进标题或副标题）。

## 交付前自查

技能里带一段可直接运行的**文字重叠检测**代码，以及溢出、空白、字号、去 AI 味五类检查。生成后跑一遍再交付。

## 配套

- 要转成 PPT 图片：用 `html-to-ppt` 技能
- 要 PDF 报告：用 `novocube-fde-report-style` 技能
- 文案去 AI 味：用 `avoid-ai-writing-cn` 技能
